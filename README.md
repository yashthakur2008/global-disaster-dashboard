# Global Disaster Dashboard

An open, public-first dashboard for global multi-disaster awareness. The first milestone is a God's Eye View inspired frontend shell: a dark mission-control interface, hazard layer rail, global map preview, live feed panel, and clear safety language.

## Safety stance

This project is for awareness only. It must always link back to official sources and tell users to follow emergency services and local authorities for protective action.

## Development

```bash
npm install
npm run dev
npm run build
```

## First frontend milestone

- GEV-like dark dashboard shell
- Data layer rail
- Global hazard map preview
- Hazard summary cards
- Live signal feed panel
- Open-data and official-alert language
